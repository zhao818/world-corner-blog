# Cursor写代码狠活

> 2026-07-03 · 美好需要创造 · AI提效实战派

---
很多人下载了 Cursor，写代码的姿势还是老一套——把它当"高级版 ChatGPT"，复制报错丢过去，或者让它帮忙写个简单的组件。

你这是把特斯拉当老头乐在开。

Cursor 真正的恐怖之处，在于它能深度感知你的整个项目上下文。今天直接上几个能让你生产力起飞的核心技巧。

---

## 壹 · 别盲目 @All，学会精准喂食

很多人一按 @ 就选整个文件夹。结果 AI 满载，反馈变慢，还经常胡言乱语。

**精准喂食三原则：**

`@Files` 和 `@Folders`——只在涉及跨文件逻辑时，精准指定相关的 2-3 个文件，别贪多。

`@Web`——如果你在用最新版的框架或库，让 AI 现学现卖，彻底告别幻觉。比如 `@Web [最新的文档链接]`。

`@Code`——引用特定函数，避免整文件过载。上下文越小，AI 越精准。

**✦ 给 AI 输入的上下文越精准，它吐出来的 Bug 就越少。**

---

## 贰 · 规则文件给 AI 注入灵魂

每次都要对 Cursor 说"请用 TypeScript、用 Hooks 写法、不要删我的注释"？烦不烦。

在项目根目录建一个规则文件，这是你和 AI 的灵魂契约：

```
你是一个精通 React 和 TypeScript 的前端专家。
1. 始终使用 TypeScript，严格定义 Interface。
2. 关键逻辑附中文注释，解释为什么这么做。
3. 不删除已有代码，只追加新逻辑。
```

新版 Cursor 推荐用 `.cursor/rules/*.mdc` 格式，支持按文件类型自动匹配、Agent 智能选择、手动引用等触发方式。在 monorepo 项目里，子目录规则会覆盖根目录规则。

一旦配好，Cursor 写的每一行代码都会变成你喜欢的形状，再也不用反复调教。

**✦ 最好的调教，是一次性的。**

## 叁 · Composer 模式——从写代码到改世界

`Cmd + I`（Mac）或 `Ctrl + I`（Windows），这是 Cursor 的大招。

普通 Chat 只能在一个文件里小打小闹，Composer 是多文件协同联动。你写一句话，它像章鱼触手一样同时创建新文件、改路由、更新组件。

比如你想加一个用户登录功能：
- 以前：建文件→写 API→改路由→加状态→改 UI，五六个文件来回切
- Composer：写下"帮我实现一套 JWT 登录逻辑"，然后狂按 Accept

Composer 是 Cursor 自研模型，速度是同等智能水平的 4 倍，大部分交互 30 秒内完成。你甚至可以同时跑多个 Agent 对比结果，选最好的那个合并。

**✦ 未来的开发者是指挥家，不是演奏家。**

---

## 肆 · 先规划再执行

Agent 输入框可以切换至 Plan 模式——让 AI 先分析代码库、提出澄清问题、生成实施计划，等你确认后再动手。

芝加哥大学研究发现，资深开发者更倾向于先规划再编码。这不是慢，是谋定而后动。

遇到 AI 越改越乱的情况，不要继续对话——直接回滚到上一个 commit，重新细化 Plan 再跑一次。

此外，用 `&` 前缀可以把任务推到云端 Agent 后台运行，不占本地资源，适合"修复 CI""调查 Issue"这类长耗时活。

**✦ 想清楚再动手，比边想边动手快十倍。**
