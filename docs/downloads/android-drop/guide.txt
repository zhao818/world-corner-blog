安卓拖拽传文件 · 使用说明

把电脑上的文件拖到桌面的纸飞机图标，就能发到自己绑定的安卓手机。第一次使用请准备一根支持传输数据的 USB 线。

第一次安装和绑定
1. 在 Windows 电脑上双击「安卓拖拽传文件-安装.exe」，按提示完成安装。桌面会出现「安卓拖拽传文件」纸飞机图标。
2. 在手机的「设置 → 开发者选项」中开启「USB 调试」。如果找不到开发者选项，可按手机品牌的说明先启用它。
3. 用 USB 数据线连接电脑，解锁手机。在手机弹出的「允许 USB 调试」提示中确认这台电脑。
4. 双击桌面的纸飞机图标。对照列表里的品牌和型号，输入自己手机前的编号，按回车。看到「已绑定」就可以发送了。

日常发送和接收
在电脑上选中一个或多个文件、文件夹，拖到纸飞机图标上松开。窗口会显示目标手机、连接方式和成功项数。打开手机的「文件管理 → 下载（Download）」查看文件。发送同名文件会覆盖下载目录里原来的文件。

拔掉数据线，用 Wi-Fi 发送
先让手机和电脑连接同一个可信 Wi-Fi，暂时保持 USB 连接。双击纸飞机图标，在菜单中输入 W 并按回车。看到「无线连接成功」后即可拔线，照常拖拽发送。

遇到问题
· 手机列表为空：解锁手机，确认已允许 USB 调试，再在电脑窗口按回车刷新。如果手机只能充电，请换一根数据线。部分机型还需安装手机厂商的 Windows USB 驱动。
· 提示「找不到已绑定的手机」：重新接上 USB 线即可有线发送。要恢复无线发送，请让两端连接同一 Wi-Fi，再双击图标，输入 W 并按回车。
· 要换一台手机：用 USB 连接并授权新手机，双击图标，输入 B 并按回车，然后选择新手机的编号。

再次查看说明：在 Windows 开始菜单搜索「安卓拖拽传文件 使用说明」。
