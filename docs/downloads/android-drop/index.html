安卓拖拽传文件

把 Windows 电脑里的文件拖到桌面纸飞机图标，就能发送到自己绑定的安卓手机。

下载 Windows 安装包

版本 1.0.1 · 约 4.5 MB · 附中文使用说明

第一次使用#

  1. 在 Windows 电脑上运行安装包，桌面会出现「安卓拖拽传文件」纸飞机图标。
  2. 手机开启 USB 调试，用数据线连接电脑，在手机上授权。双击纸飞机，选择自己要绑定的手机。
  3. 把文件或文件夹拖到纸飞机图标上，在手机的「下载」目录查看。

手机与电脑连接同一 Wi-Fi 后，可以在程序菜单输入 W 开启无线传输。看到无线连接成功后即可拔线。
