# 🧩 推理解谜素材库

## 用途

写公众号文章时，按主题匹配最合适的谜题，自然融入正文。

不是发谜题本身，而是用谜题的逻辑框架来包装观点。

## 来源网站

| 网站 | 语言 | 特点 |
|------|------|------|
| 33IQ | 中文 | 海量中文推理题，有社区评分 |
| gridpuzz.com | 中文 | 网格逻辑题 |
| 贝克街推理学院 | 中文 | 经典推理 |
| cn.gridpuzzle.com | 中文 | 网格谜题中文站 |
| ZebraPuzzles.com | 英文 | 经典「谁养鱼」类 |
| BrainBashers.com | 英文 | 智力题+逻辑题 |
| PuzzlePicnic.com | 英文 | 高质量谜题集合 |

## 类别说明

| 目录 | 包含 | 适用文章类型 |
|------|------|------------|
| `deduction/` | 纯逻辑推理（谁养鱼、帽子颜色等） | 讲方法论、决策框架 |
| `grid-puzzle/` | 网格排除（数独变体、逻辑网格） | 讲信息整合、分类思维 |
| `lateral-thinking/` | 横向思维、脑筋急转弯 | 讲创新、打破常规 |
| `pattern/` | 图形/序列/归纳推理 | 讲模式识别、趋势判断 |
| `strategy/` | 博弈论、囚徒困境、决策谜题 | 讲竞争策略、合作 |
| `life-analogy/` | 可映射到现实生活的推理 | 通用 |

## 使用流程

1. 文章初稿完成
2. 分析文章主题/关键词
3. 搜 `index.json` 匹配 mappings 字段
4. 选 1-2 道最贴合的谜题
5. 按「融入建议」嵌入正文

## 维护

- 新谜题参考来源网站的经典题或精选题
- 每道题必须填 mappings 字段（能映射到哪些文章主题）
- index.json 自动/手动同步
