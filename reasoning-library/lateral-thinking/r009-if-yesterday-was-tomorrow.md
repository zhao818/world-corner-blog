## 题目

一个人说：

**「如果昨天是明天的话就好了，那么今天就是周五了。」**

请问：实际今天是周几？

（注意：这不是脑筋急转弯，是一个严格的逻辑推理题）

## 解答

答案是**周日**。

推理过程：

设实际今天是 X，实际昨天是 X-1，实际明天是 X+1。

「如果昨天是明天」有两种理解方式：

**理解A（把实际的昨天替换成假设的明天）：**
- 假设的昨天 = 实际明天 = X+1
- 假设的今天 = 假设的昨天 + 1 = X+2
- 已知假设的今天 = 周五
- 所以 X+2 = 周五 → X = 周三

**理解B（把假设的昨天设定为实际的明天）：**
- 假设的昨天 = 实际明天 = X+1
- 假设的今天 = X+1+1 = X+2 ... 不对，重新推

正确推法（理解B）：
- 「明天」这个词在假设世界里指的是什么？
- 「昨天是明天」意思是：假设世界里的「昨天」等于现实世界里的「明天」
- 设假设的今天 = 周五
- 假设的昨天 = 周四
- 这个假设的昨天（周四）等于现实世界的明天
- 所以现实世界的明天 = 周四 → 现实今天 = **周三**

所以这道题有两个答案，取决于你怎么理解「如果昨天是明天」这句话——要么周三，要么周日。最常见的出题者预设答案是**周三**。
