## 题目

纸上画了3行3列共9个点，排成正方形（就像手机解锁图案的3×3点阵）。

要求：用**连续4条直线**（笔不离开纸面）**一笔画过全部9个点**。

试着在脑子里画一画，或者直接在纸上试试。

## 解答

大多数人卡住是因为默认了一个不存在的约束——**不能画出点的边界**。

正确答案很简单：把线画**出**这个9个点的正方形范围就行。

```
①→②→③→↘（延伸到外面）
               ↙
⑧←⑦←⑥←↙ （延伸到外面）
↓
⑤→④→↘（延伸到外面）
        ↙
        ⑨
```

四条线：从左上角点开始 → 向右穿过第一行3个点并往外延 → 斜向左下穿过第3列中点并往外延 → 向左穿过第三行3个点并往上延 → 斜穿回剩下的点。

关键教训：**你给自己画了一条不存在的边界。**

## 融入建议

适合场景：讲创新、打破思维定势、跨界思考。
融入位置：阻力最大时抛出这个谜题——"现在我问你，你给自己设了什么边界？"

最佳搭档：跟R002狼羊菜过河一起用——一个讲「约束是真的」，一个讲「约束是假的」，对比着看。
