## 题目

小明说："如果昨天是明天的话就好了，那么今天就是周五了。"

请问：句中的"今天"实际上是周几？

## 解答

**答案：今天是周三或周日。**（这道题有两种理解）

### 理解一：假设昨天变成明天

设今天是 X。
- 实际的昨天 = X-1
- 实际的明天 = X+1
- 条件：如果 X-1 变成 X+1（即昨天变成明天）
- 那么"今天"就会往后推2天：X+2
- 条件说"今天是周五"：X+2 = 周五
- 所以 X = **周三**

### 理解二：假设明天变成昨天

设今天是 X。
- 实际的明天 = X+1
- 条件：如果 X+1 变成 X-1（即明天变成昨天）
- 那么"今天"就会往前推2天：X-2
- 条件说"今天是周五"：X-2 = 周五
- 所以 X = **周日**

### 为什么两种都对？

关键在"昨天是明天"这句话的主语：
- "昨天"是主语 → 昨天变成明天 → 今天+2
- "明天"是宾语 → 明天变成昨天 → 今天-2

中文的歧义让这道题有了两个答案。
