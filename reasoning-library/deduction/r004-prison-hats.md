## 题目

国王对三个囚犯说：你们每人戴了一顶帽子，帽子要么红色要么蓝色。至少有一顶红帽子。

你们能看到别人帽子的颜色，但看不到自己的。

谁能第一个说出自己帽子的正确颜色，谁就被释放。答错处死。

三个人沉默了好久，然后突然有一个人说出了正确答案。

请问：他是怎么推理出来的？他戴的是什么颜色的帽子？

## 解答

答案是**红帽子**。推理过程（以戴红帽子的A的视角）：

1. A看到B和C都是红帽子 → A知道自己可能是红或蓝
2. 但如果A是蓝帽子 → B会看到A蓝、C红 → B会想："如果我也是蓝，那C看到的全是蓝——但国王说至少有一顶红，C应该立刻说出自己是红才对"→ B观察后发现C没说话 → B就知道自己一定是红，B就会开口
3. 但B没有开口 → 说明A不是蓝
4. 所以A是红

核心机制是**彼此观察到的沉默时间**——沉默本身就是信息。

## 融入建议

适合场景：讲间接信息、公共知识、推理链。
融入位置：开头抛出谜题让读者想 → 正文映射到现实（"你老板没回复你邮件，这本身就是一条信息"）→ 提炼：重要的不仅是说了什么，还有**没说什么**。

变体：同理可以推广到「蓝眼睛岛」问题（100个蓝眼人全部离开），适合讲共识的建立过程。
